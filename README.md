# Hostel Yaar — Backend

FastAPI backend for **Hostel Yaar**, a hostel discovery platform for Pakistan.
Handles user authentication (JWT), password reset via OTP, and (soon) hostel
and booking data.

The Flutter mobile app lives at [hostel-yaar-app](https://github.com/saadkhanii/hostel-yaar-app).

## Stack

- **FastAPI** — REST API framework
- **SQLAlchemy** — ORM
- **SQLite** (dev) / **PostgreSQL** (planned) — database
- **Pydantic** — request/response validation
- **python-jose** + **passlib[bcrypt]** — JWT and password hashing
- **pydantic-settings** — environment-based config

## Project structure
app/
├── main.py # FastAPI app entry point
├── config.py # Settings loaded from .env
├── database.py # SQLAlchemy engine + session
├── models.py # SQLAlchemy models (User, PasswordResetOTP)
├── schemas.py # Pydantic request/response schemas
├── routers/
│ └── auth.py # /auth/* endpoints
└── utils/
├── security.py # password hashing + JWT helpers
├── otp.py # OTP generation + storage
├── google_auth.py # Google ID token verification
└── deps.py # FastAPI dependencies (get_current_user, etc.)


## Endpoints

| Method | Path                      | Description                        |
|--------|---------------------------|------------------------------------|
| POST   | `/auth/signup`            | Create account, returns JWT        |
| POST   | `/auth/login`             | Authenticate, returns JWT          |
| POST   | `/auth/forgot-password`   | Send 6-digit OTP to email (dev: logged to terminal) |
| POST   | `/auth/verify-otp`        | Validate OTP code                  |
| POST   | `/auth/reset-password`    | Set new password using OTP         |
| POST   | `/auth/google`            | Sign in / up via Google ID token   |

Interactive API docs: `http://localhost:8000/docs` (auto-generated by FastAPI).

## Local setup

```bash
# 1. Clone
git clone https://github.com/saadkhanii/hostel_yaar_backend.git
cd hostel_yaar_backend

# 2. Create and activate virtualenv
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS / Linux

# 3. Install dependencies
pip install -r requirements.txt

# 4. Copy env template and fill in values
copy .env.example .env

# 5. Run
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
--host 0.0.0.0 is required if you want to hit the API from a physical
Android device on the same Wi-Fi.

Notes
Passwords are hashed with bcrypt and never stored in plaintext.

JWTs are signed with JWT_SECRET_KEY from .env (change this in production).

In dev mode, OTP codes are printed to the terminal instead of emailed.
SMTP integration is pending.

The dev database is a local SQLite file (hostel_yaar_dev.db) and is
git-ignored. Migrations will move to Alembic before any production deploy.
